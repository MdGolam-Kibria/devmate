# M0 — Foundation

Status: **COMPLETED** (2026-10-05)

## Goal

A buildable, runnable, observable Spring Boot skeleton on the agreed baseline, which later milestones build on.

## Delivered

- Maven multi-module root (`devmate/pom.xml`) on Boot parent 4.1.1 with Java 25. The enforcer requires JDK ≥ 25,
  Maven ≥ 3.9, no duplicate dependency declarations, and no SNAPSHOT dependencies in release builds.
- `devmate-client`: Web MVC on virtual threads, Actuator with health, liveness/readiness probes and info (build +
  Java metadata), and graceful shutdown.
- Configuration: `application.yml` plus the `dev` and `json-logs` profiles, with environment-variable overrides
  (`DEVMATE_PORT`, `DEVMATE_SHUTDOWN_TIMEOUT`).
- Logging: correlation prefix `[app,requestId]`, and ECS JSON under `json-logs`.
- `RequestIdFilter`: validates or generates `X-Request-Id`, echoes it on the response, and sets MDC `requestId`.
  Malformed values are replaced so they can't inject into the logs.
- Maven wrapper pinned to 3.9.11.
- Docs: README, architecture overview, ADR-0001, this file.

## Verification

```bash
JAVA_HOME=<jdk-25> ./mvnw clean verify   # BUILD SUCCESS
```

| Suite                          | Type        | Tests | What it proves                                                          |
|--------------------------------|-------------|-------|-------------------------------------------------------------------------|
| `RequestIdFilterTest`          | unit        | 8     | Valid id reused; null, blank, whitespace, CR/LF, HTML and over-long ids replaced; MDC cleared, including when the chain throws |
| `ActuatorHealthIT`             | integration | 10    | `health`, `liveness` and `readiness` return `UP`; details hidden; `info` has build metadata; `env`, `beans`, `configprops` and `heapdump` return 404; `X-Request-Id` on responses |

Manual smoke test: `java -jar devmate-client/target/devmate-client-0.1.0-SNAPSHOT.jar`.
`GET /actuator/health` returned `{"groups":["liveness","readiness"],"status":"UP"}`, and SIGTERM logged
"Graceful shutdown complete".

## Not in scope (by design)

MCP server/client, LLM, RAG, DB, Kafka, Redis, OTel, K8s. `devmate-files-mcp` and `devmate-git-mcp` are created in M1 and M4.

## Known limitations

- No OpenTelemetry tracing yet, so there is no `traceId`/`spanId` in logs.
- No container image yet (M14).
- The Actuator port is the application port. Splitting `management.server.port` is a production-hardening decision (M14).
